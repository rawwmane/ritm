# Ритм

Трекер двух привычек с геймификацией: утренний выход до спортплощадки и жизнь без ленты.
Плюс «колода» мини-задач по проектам, которая открывается вместо соцсетей, когда тянет залипнуть.

Веб-приложение (PWA) без сервера и регистрации: данные хранятся только на телефоне (`localStorage`),
резервная копия — JSON-файл через меню «Ещё».

## Установка на iPhone

1. Открыть адрес приложения в Safari.
2. «Поделиться» → «На экран Домой».
3. Открывать всегда с иконки: у Safari и у иконки разные хранилища.

## Файлы

- `logic.js` — чистая логика: серии, заморозки, XP, уровни, ачивки (без DOM).
- `app.js` — интерфейс.
- `dots.js` — точечный шрифт для цифр, круговая диаграмма, кольцо уровня, иконки (inline-SVG, без внешних шрифтов).
- `seed.js` — стартовые проекты, карточки, награды и правила (используется только при первом запуске).
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и установка на экран.

## Локальный запуск

```
python -m http.server 8765
```

и открыть http://127.0.0.1:8765/.
